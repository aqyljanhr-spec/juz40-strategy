# JUZ40 Strategy Platform — іске қосылатын веб-жоба

Бұл **тек HTML прототипі емес**: FastAPI сервері, SQLite дерекқоры, WebSocket синхрондау, адаптивті клиент, Excel/PDF экспорты, AI API қосылуы бар.

## Жергілікті іске қосу

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
uvicorn app:app --host 0.0.0.0 --port 8000
```

Браузерде `http://localhost:8000` ашыңыз. TEST және LIVE деректері бөлек. Дерекқор `strategy.sqlite3` түрінде жасалады.

## Интернетке жариялау

1. Жобаны Git репозиторийіне жүктеңіз.
2. Render/Railway/Fly.io тәрізді **Python серверін және WebSocket-ті** қолдайтын хостқа орналастырыңыз. Бұл жоба Vercel статикалық deploy-на тікелей арналмаған.
3. Орындау командасы: `uvicorn app:app --host 0.0.0.0 --port $PORT`.
4. SQLite дерекқорын **тұрақты дискке** орналастырып, `JUZ40_DB=/data/strategy.sqlite3` орнатыңыз, әйтпесе қайта deploy кезінде жауаптар өшіп қалуы мүмкін. Балама — PostgreSQL миграциясы.
5. AI үшін құпия орта айнымалысы `OPENAI_API_KEY` енгізіңіз. Онсыз AI батырмасы қате көрсетеді, ойдан шығарылған есеп бермейді. Қажет болса `OPENAI_MODEL` енгізіңіз.
6. Хост берген HTTPS доменді қатысушыларға таратыңыз; домен алдын ала брондалмаған.

## Бекітілген функциялар

- 76 қызметкер, бір бөлім ішінде бөлінген 7 топ (Әдістеме 2, Сапа 3, IT 2). Бастапқы капитан ретінде әр топтың бірінші қызметкері уақытша белгіленген, әкімші өзгерте алады.
- Аты-жөнін таңдап кіру, автоматты Check-in; қатысушылар тек өз топтарының жауаптарын көреді; әкімші барлық жауаптарды көреді.
- 1-блок: 1–3 жеке мәселе, әкімші ашатын жазу/дауыс/қорытынды кезеңдері, дәл 3 дауыс, қорытындыға дейін дауыс түзету, ашық дауыс санын тек әкімші қарайды.
- 2-блок: бөлім және JUZ40 1/3/5 жылға бөлек; Әдістемеге қосымша JUZ40 Баспасы.
- 3 және 4-блок: әрқайсысына бір үлкен топтық жауап.
- Капитан ортақ жауаптарды өңдейді; аяқтағаннан кейін әкімші қайта ашады. Блоктарды әкімші ашады/жабады.
- Серверлік сақтау, WebSocket жаңарту, offline мәтін қараламасы, TEST/LIVE бөлек режим, аудит журналы.
- Топтық PDF және жалпы XLSX экспорт; AI модульдері мен есеп нұсқаларын сақтау.

## Маңызды шектеулер

**Пайдаланушы аты-жөнді ғана таңдауды бекітті. Сондықтан ешбір рөл, дауыс немесе әкімші құқығы сенімді тексерілмейді.** Бұл нұсқа адал қатысушыларға арналған басқарылатын іс-шара үшін ғана жарамды. Жеке деректерге шынайы access control орнату үшін SSO немесе invite/PIN қажет. Бұл жерде `admin_*` операциялары криптографиялық расталмайды.

- Нақты интернет доменінде әлі жарияланған жоқ: хост аккаунты қажет.
- Офлайн қаралама сол браузердің localStorage ішінде сақталады; браузер жады тазаланса жоғалуы мүмкін. Кезең жабылған соң синхрондау серверде қабылданбайды.
- PDF-де тек сол топтың сақталған ортақ мәтіндері беріледі. Excel толық.
- Бір құрылғыда бірнеше пайдаланушы бірінің атын таңдап кіре алады — дауыс авторлығына кепілдік жоқ.
- SQLite бір серверлік реплика үшін жарамды; көп реплика/үлкен жүктеме үшін PostgreSQL-ге көшу ұсынылады.
- PDF және Excel сілтемелеріне кіру аты-жөнге негізделгендіктен шынайы құпиялылық қорғанысын қамтамасыз етпейді.
- AI API қызметіне шығын туындауы мүмкін; кілтті клиент кодының ішіне жазбаңыз.


## Render + Supabase PostgreSQL орналастыру

1. Supabase-та **New project** жасап, Project Settings → Database → Connection string ішінен **Session pooler** URI таңдаңыз. Оны ешкімге жібермеңіз; Render Environment ішіне `DATABASE_URL` ретінде қойыңыз. Құпиясөзде арнайы таңбалар болса, URL encoding қажет.
2. Жобаны GitHub репозиторийіне жүктеңіз (жеке репозиторий болғаны дұрыс).
3. Render → New → Web Service → GitHub repository. Runtime: Python; Build Command: `pip install -r requirements.txt`; Start Command: `uvicorn app:app --host 0.0.0.0 --port $PORT`.
4. Render → Environment: `DATABASE_URL` = Supabase connection URI. Егер AI функциясы қолданылса `OPENAI_API_KEY`-ді де тек Environment ішіне қосыңыз.
5. Бір ғана Render instance пайдаланыңыз; state толық JSON құжат ретінде сақталады және бірнеше серверлік process арасында атомарлық optimistic locking жоқ. Қолданар алдында 76 параллель қатысушыға жүктеме тестін өткізу қажет.
6. Render берген HTTPS URL-ді ашып, TEST режимінде тіркелу, дауыс беру, топтық жауап, PDF және Excel-ді тексеріңіз. LIVE режиміне сынақ деректерін көшірмеңіз.

**Қауіпсіздік:** Бұл сайтта қолданушы аты-жөнін таңдап кіретіндіктен, әкімші рөлі сенімді қорғалмайды. Бет URL-ін құпия сақтау қауіпсіз аутентификацияны алмастырмайды. Нақты қолданғанда әкімші рөлін қорғау нұсқасын қайта қарастыру ұсынылады.
